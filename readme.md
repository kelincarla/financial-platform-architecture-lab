# Financial Platform Architecture Lab

Laboratório para estudo de documentação de arquitetura utilizando LikeC4.

## Tecnologias

- LikeC4
- GitHub Pages
- GitHub Actions

## Executar

npm install
npm run dev

## Gerar documentação

npm run build

## Publicação

O deploy é realizado automaticamente pelo GitHub Actions após um push na branch `main`.
